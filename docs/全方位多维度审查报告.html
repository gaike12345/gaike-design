🔥 最紧急的 10 项修复（立即处理）

  • 轮换所有密钥 — JWT_SECRET 弱值可伪造任意用户 Token，API Key 可能已泄露
  • 关闭 Docker 端口映射 — PostgreSQL、Redis、后端端口直接暴露公网，极易被入侵
  • 生产环境强制强密钥 — Docker 默认 JWT_SECRET 和数据库密码为弱值，必须要求用户配置
  • 配置 Express trust proxy — 攻击者可伪造 X-Forwarded-For 绕过 IP 限流
  • 修复注册 UID 竞态 — 当前实现与 ADR-004 不符，存在 TOCTOU 竞态漏洞

  • 修复 AudioPage token key 不一致 — 生产环境鉴权可能失效
  • JWT 增加撤销机制 — 登出/改密码/封禁后原 Token 仍有效
  • PM2/Docker 不以 root 运行 — 容器逃逸风险
